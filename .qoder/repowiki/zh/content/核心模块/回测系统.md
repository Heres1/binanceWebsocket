## 简介

这是一个基于 Rust 的事件驱动回测系统，专为 Binance 期货交易设计。系统提供了多种回测模式，包括历史 K 线回测、实时数据回放回测，以及高级的 V2 策略引擎。该系统采用事件驱动架构，支持参数优化、多策略类型和复杂的风控机制。

**更新** 系统现已从单一动量策略扩展为支持做多和做空的双向交易系统，新增突破检测算法和Intra-bar模拟技术，引入V2多策略优化框架，显著增强了策略的多样性和鲁棒性。

## 核心组件

### 回测引擎 (BacktestEngine)

回测引擎是系统的核心组件，负责协调整个回测流程。它支持两种回测模式：

1. **K线模式**: 使用历史 K 线数据进行回测
2. **回放模式**: 使用录制的实时数据进行回放

引擎内置了完整的交易逻辑，包括入场、出场、风控和手续费计算。

**更新** 新增了增强的RSI过期机制和天花板约束，改进了Intra-bar止损止盈检查，支持做多和做空双向交易。

### V2 多策略引擎 (StrategyV2)

**更新** 新增了rsi_oversold_bars计数器用于跟踪超卖信号持续时间，并实现了RSI过期机制：

```mermaid
CheckOversold --> |是| SetFlag[设置rsi_was_oversold=true]
SetFlag --> ResetBars[rsi_oversold_bars = 0]
CheckOversold --> |否| CheckWasOversold{之前是超卖?}
CheckWasOversold --> |是| IncrementBars[rsi_oversold_bars += 1]
IncrementBars --> CheckExpiration{rsi_oversold_bars > 30?}
CheckExpiration --> |是| ExpireSignal[重置rsi_was_oversold=false<br/>rsi_oversold_bars = 0]
CheckExpiration --> |否| Continue[继续监控]
CheckWasOversold --> |否| Continue
ExpireSignal --> Continue
Continue --> End([等待入场信号])
```

#### Intra-bar 止损止盈机制

**更新** V2 引擎引入了 Intra-bar（K线内）止损止盈检查：

```mermaid
flowchart TD
EnterTrade[入场] --> MonitorKline[监控K线高低点]
MonitorKline --> CheckStopLoss{K线低点<=止损价?}
CheckStopLoss --> |是| StopLoss[止损出场]
CheckStopLoss --> |否| CheckTrailing{追踪止损?}
CheckTrailing --> |启用| CheckTrailingTrigger{达到追踪价格?}
CheckTrailingTrigger --> |是| TrailingExit[追踪止损出场]
CheckTrailingTrigger --> |否| CheckTakeProfit{K线高点>=止盈价?}
CheckTrailing --> |不启用| CheckTakeProfit
CheckTakeProfit --> |是| TakeProfit[止盈出场]
CheckTakeProfit --> |否| CheckTimeout{超时检查}
CheckTimeout --> |超时| TimeoutExit[超时出场]
CheckTimeout --> |未超时| CheckRSI{RSI检查}
CheckRSI --> |超买| RSIClose[RSI超买出场]
CheckRSI --> |正常| MonitorKline
StopLoss --> Exit[出场完成]
TrailingExit --> Exit
TakeProfit --> Exit
TimeoutExit --> Exit
RSIClose --> Exit
```

## 性能考虑

### 回测性能优化

1. **内存优化**: V2 引擎支持预加载数据到内存，避免重复 IO 操作
2. **并行处理**: 使用 tokio 异步运行时提高并发性能

## 故障排除指南

### 常见问题及解决方案

#### 数据下载失败

**问题**: 无法从 Binance 下载历史数据
**解决方案**:
1. 检查网络连接和代理设置
2. 验证 API 密钥权限
3. 检查请求频率限制
4. 确认交易对存在且支持历史数据

#### 回测结果异常

**问题**: 回测结果显示异常的交易信号
**排查步骤**:
1. 检查输入数据质量
2. 验证策略参数设置
3. 确认技术指标计算正确
4. 检查风控规则配置

#### 性能问题

**问题**: 回测执行速度过慢
**优化建议**:
1. 使用预加载数据模式
2. 调整参数网格规模
3. 优化硬件资源配置
4. 检查系统资源使用情况

#### RSI过期机制问题

**问题**: RSI超卖信号过期机制不工作
**排查步骤**:
1. 检查rsi_oversold_bars计数器是否正确递增
2. 验证过期阈值（30根1m K线）设置
3. 确认rsi_was_oversold标志重置逻辑
4. 检查RSI参数配置是否合理

#### V2策略优化问题

**问题**: V2多策略优化结果不理想
**排查步骤**:
1. 检查策略类型配置是否正确
2. 验证参数网格范围是否合理
3. 确认做多和做空参数平衡
4. 检查手续费率设置
