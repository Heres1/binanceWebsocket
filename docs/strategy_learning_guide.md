# BTC 动量短线交易策略 - 完整学习指南

## 一、策略整体架构

### 1.1 策略定位
- **类型**: 高频动量短线策略（Momentum Scalping）
- **交易品种**: BTCUSDT **现货**（Spot，非合约）
- **交易所API**: `api.binance.com`（现货REST）+ `stream.binance.com`（现货WebSocket）
- **方向**: 纯做多（`allow_short = false`），买入BTC现货 → 卖出BTC现货
- **目标**: 捕捉 BTC 短期上涨动量，在趋势延续阶段入场，快速获利出场
- **账户**: ~$200 本金，每笔 0.002 BTC（约 $128 @ $64000）
- **无杠杆**: 现货交易不使用杠杆，实际持有BTC资产

### 1.2 数据源（三路实时数据流）
策略同时订阅三种 Binance WebSocket 数据流：

| 数据流 | 作用 | 触发频率 |
|--------|------|----------|
| **K线 (Kline)** | 更新 EMA、RSI、ATR、ADX 指标 | 1分钟/5分钟收盘时 |
| **聚合成交 (AggTrade)** | 计算实时买卖量比率 | 每笔成交实时 |
| **最优盘口 (BookTicker)** | 触发入场/出场判断 + 盘口强度分析 | 盘口变动实时 |

**决策触发点**: 所有入场/出场决策在 BookTicker 事件中做出，因为它是最高频且代表最新价格的数据源。

### 1.3 决策流程

```
BookTicker 到来
  → 更新盘口价格
  → 日重置检查（跨天清零统计）
  → 如果持仓中 → 检查出场条件（阶梯式保护）
  → 如果空仓 → 检查入场条件（多因子评分）
```

## 二、技术指标详解

### 2.1 EMA - 指数移动平均线

**用途**: 判断趋势方向和强度

| EMA | 周期 | 数据源 | 含义 |
|-----|------|--------|------|
| EMA(7) - 1分钟 | 7根1mK线 | 1分钟K线 | 短期价格中心 |
| EMA(21) - 1分钟 | 21根1mK线 | 1分钟K线 | 中期价格中心 |
| EMA(7) - 5分钟 | 7根5mK线 | 5分钟K线 | 短期趋势方向 |
| EMA(21) - 5分钟 | 21根5mK线 | 5分钟K线 | 中期趋势方向 |
| EMA(50) - 5分钟 | 50根5mK线 | 5分钟K线 | 宏观趋势环境 |

**计算公式**:
- 预热期（前N根）: 使用简单平均 SMA = sum(prices) / N
- 正式计算: `EMA = price × k + prevEMA × (1-k)`，其中 `k = 2/(N+1)`

**关键用法**:
- `EMA7 > EMA21`（5分钟） → 趋势向上（`trend_up`）
- `(EMA7-EMA21)/EMA21 × 100%` → 趋势强度（`trend_strength`）
- `EMA21斜率` = `(当前EMA21 - 上一根EMA21) / 上一根EMA21 × 100%` → 趋势动能
- 价格距EMA50距离 → 趋势延伸程度

### 2.2 RSI - 相对强弱指数

**用途**: 判断超买超卖状态，寻找反弹入场点

**参数**: RSI(14)，使用1分钟K线
**计算**: Wilder平滑法
- `RS = avg_gain / avg_loss`
- `RSI = 100 - 100/(1+RS)`

**关键阈值**:
| 阈值 | 配置值 | 含义 |
|------|--------|------|
| 超卖线 | 40 | RSI < 40 时标记"曾超卖" |
| 反弹确认 | 45 (40+5) | RSI回升到45以上时确认反弹 |
| 超买线 | 100 (禁用) | 不使用RSI退出 |
| 入场上限 | 65 | 突破路径要求RSI<65，防高位追涨 |

**RSI状态机**:
```
RSI跌破40 → 设置 rsi_was_oversold = true
  → RSI回升到45以上 → 触发"RSI反弹"入场信号
  → 30根1mK线(30分钟)未入场 → 信号过期清零
```

### 2.3 ATR - 平均真实波动幅度

**用途**: 动态止损距离计算、波动率环境过滤

**参数**: ATR(14)，使用5分钟K线，保留最近100个历史值

**计算**:
- `True Range = max(H-L, |H-前收|, |L-前收|)`
- `ATR = (prevATR × 13 + TR) / 14` （Wilder平滑）

**核心应用**:
- **止损距离**: `entry_price - 8.5 × ATR` = 初始止损价
- **追踪触发**: 浮盈达到 `3.0 × ATR` 时激活追踪止损
- **追踪距离**: 追踪止损 = `最高价 - 2.0 × ATR`
- **百分位过滤**: 当前ATR在历史100个值中的排名（目前禁用: 0-100%全通过）

**为什么用ATR而不是固定%**:
BTC的波动是变化的。牛市高波动时ATR大→止损宽→不被正常波动止出；
低波动震荡时ATR小→止损紧→快速止损减少损失。

### 2.4 ADX - 平均方向指数

**用途**: 判断当前市场是"趋势市"还是"震荡市"

**参数**: ADX(14)，使用5分钟K线

**计算**: 基于+DI和-DI的方向运动系统
- `+DI` = 上涨方向动能，`-DI` = 下跌方向动能
- `DX = |+DI - -DI| / (+DI + -DI) × 100`
- `ADX = Wilder平滑(DX)`

**关键阈值**:
| ADX值 | 含义 | 策略行为 |
|--------|------|----------|
| < 20 | 震荡市，无明显趋势 | **禁止入场** |
| 20-30 | 趋势正在形成 | 允许入场 |
| > 30 | 强趋势 | 评分加分 |

**意义**: 动量策略在无趋势的震荡市中表现差（频繁假突破），ADX过滤可大幅减少无效交易。

### 2.5 VolumeRatio - 买卖量比率

**用途**: 判断资金流向（谁在主动买/卖）

**参数**: 60秒滑动窗口

**计算**:
- 统计窗口内所有成交：`is_buyer_maker=false` → 主动买入，`is_buyer_maker=true` → 主动卖出
- `VolumeRatio = 买方成交量 / 卖方成交量`

**关键阈值**:
| 量比值 | 含义 |
|--------|------|
| > 2.5 | 强烈买盘优势（RSI反弹/均值回归要求） |
| > 1.2 | 有买盘优势（突破入场要求） |
| = 1.0 | 买卖平衡 |
| < 0.83 | 卖盘优势（当前策略不使用，仅做多） |

## 三、入场路径（三种）

### 3.1 通用前置条件（所有入场路径共享）

入场前必须通过以下检查（任一不满足则不入场）：

| 检查项 | 条件 | 配置参数 |
|--------|------|----------|
| 预热完成 | 1mK线≥21根 且 5mK线≥50根 | 硬编码 |
| 冷却时间 | 距上次交易 > 120秒 | `cooldown_seconds = 120` |
| 熔断冷却 | 不在连续止损暂停期内 | 动态 |
| 日交易次数 | 今日 < 50笔 | `max_daily_trades = 50` |
| 日亏损限制 | 今日累计亏损 < 2% | `max_daily_loss_pct = 2.0` |
| 点差正常 | bid/ask 点差 < 0.5% | 硬编码 |

### 3.2 路径一：RSI反弹入场

**核心思想**: 价格短期超卖后反弹，配合趋势和量能确认

**触发条件（全部满足）**:
1. ✅ `long_trend_env_ok` = true（趋势环境确认）
2. ✅ `entry_score >= 55`（多因子评分达标）
3. ✅ `trend_up` = true（EMA7 > EMA21，5分钟）
4. ✅ `trend_strong_enough` = true（趋势强度 ≥ 0.03%）
5. ✅ `rsi_recovering` = true（RSI曾<40，现已>45）
6. ✅ `rsi_bounce_vr_ok` = true（量比 > 2.5）
7. ✅ `bid_support` = true（买一量 > 卖一量×1.5）

**趋势环境确认（`long_trend_env_ok`）需要全部满足**:
- 价格在EMA50上方至少 0.15%
- 价格距EMA50不超过 1.0%（防趋势末端）
- EMA21斜率 > +0.03%（确认上升动能）
- EMA50宏观方向上升（对比100分钟前的EMA50值）

**典型场景**: 上升趋势中出现短暂回调（RSI跌至超卖），随后买盘重新涌入推动价格回升。

### 3.3 路径二：突破入场

**核心思想**: 价格突破近期高点，趋势加速延续

**触发条件（全部满足）**:
1. ✅ `long_trend_env_ok` = true（趋势环境确认）
2. ✅ `entry_score >= 55`（多因子评分达标）
3. ✅ 当前价 > 最近19根1mK线最高价（突破确认）
4. ✅ 突破幅度 > 0.05%（避免假突破）
5. ✅ `vol_ratio > 1.2`（买盘配合）
6. ✅ RSI < 65（防高位追涨）
7. ✅ `trend_up` = true 且 `trend_strong_enough` = true
8. ✅ `breakout_slope_ok` = true（EMA21斜率 > 0.05%）

**与RSI反弹的区别**: 突破路径不需要RSI超卖历史，但要求更强的趋势动能（斜率门槛更高0.05% vs 0.03%）。

### 3.4 路径三：均值回归入场

**核心思想**: 大幅急跌后的超跌反弹，不需要趋势确认

**触发条件（全部满足）**:
1. ✅ 从最近20根K线最高点下跌 > 1.2%
2. ✅ RSI < 38（极度超卖）
3. ✅ 量比 > 2.5（强买盘涌入）
4. ✅ `bid_support` = true（买一量 > 卖一量×1.5）
5. ✅ EMA21斜率 > -0.10%（不是持续暴跌）
6. ✅ `volatility_normal` = true（波动率正常）

**特殊性**:
- **不需要趋势环境确认**（不要求价格在EMA50上方）
- **不需要评分达标**（绕过55分阈值）
- **EMA21斜率保护**：斜率必须 > -0.10%，防止在持续暴跌中"接飞刀"

**典型场景**: 突发利空导致BTC闪跌>1.2%，但大量买单在底部涌入（散户恐慌抛售，机构/大户接盘）。

## 四、多因子评分系统

### 4.1 评分机制

总分 100 分，阈值 55 分（评分 < 55 不允许入场）。

| 因子 | 分值 | 条件 |
|------|------|------|
| 趋势方向 | 15分 | EMA7 > EMA21（5分钟） |
| 趋势强度 | 10分 | (EMA7-EMA21)/EMA21 ≥ 0.03% |
| ADX趋势性 | 15分 | ADX ≥ 20（或ADX未就绪时默认通过） |
| RSI反弹 | 15分 | RSI曾<40 且已回升到>45 |
| 成交量确认 | 15分 | 买卖量比 > 1.2 |
| 盘口支撑 | 10分 | 买一量 > 卖一量 × 1.5 |
| EMA21斜率 | 10分 | 斜率 > +0.03% |
| 波动率正常 | 10分 | ATR百分位在正常范围（目前0-100全通过） |

### 4.2 评分策略
- 满分 100 意味着所有因子完美对齐 → 最高信心入场
- 阈值 55 ≈ 至少需要约4-5个因子通过
- **均值回归路径绕过评分**，因为它有自己的严格条件（急跌>1.2% + RSI<38 + VR>2.5）

## 五、出场机制 - 阶梯式保护

### 5.1 出场优先级

```
阶段1: 初始止损 (ATR基础止损)
  ↓ 浮盈达到 breakeven_trigger(0.8%)
阶段2: 保本止损 (止损上移到入场价)
  ↓ 浮盈达到 atr_trailing_multiplier × ATR (约3.0×ATR)
阶段3: 追踪止损 (最高价 - 2.0×ATR)
  ↓ 浮盈继续扩大
阶段4: 硬止盈上限 (3.0%)
```

### 5.2 各出场条件详解

| 条件 | 触发 | 说明 |
|------|------|------|
| **ATR初始止损** | `price ≤ entry - 8.5×ATR` | 入场后的基础保护网 |
| **保本止损** | 浮盈曾达0.8%后回落到入场价 | 不亏钱出场 |
| **ATR追踪止损** | 浮盈达3.0×ATR后，价格回落2.0×ATR | 锁定大部分利润 |
| **硬止盈** | 浮盈 ≥ 3.0% | 利润上限保护 |
| **时间止损** | 持仓超过12小时 | 防止无限持有 |
| **僵尸早退** | 超时且浮盈<0.3%（目前禁用: 999999秒） | 释放资金 |

### 5.3 ATR动态止损举例

假设：`entry_price = 64000`, `ATR = 50`

```
初始止损 = 64000 - 8.5×50 = 63575 (距入场-0.66%)
追踪触发 = 浮盈达到 3.0×50 = $150 → price=64150
追踪激活后止损 = 最高价 - 2.0×50 = 最高价 - 100

例: 价格涨到64300(最高)后回落
→ 追踪止损 = 64300 - 100 = 64200
→ 如果价格跌到64200则平仓，锁定利润
```

### 5.4 固定%回退机制

当ATR未就绪或被禁用时，使用固定百分比：

| 参数 | 值 | 说明 |
|------|---|------|
| `stop_loss_pct` | 1.5% | 初始固定止损 |
| `breakeven_trigger_pct` | 0.8% | 保本止损触发 |
| `trailing_trigger_pct` | 1.0% | 追踪止损触发 |
| `trailing_distance_pct` | 0.8% | 追踪止损回撤距离 |

## 六、风控机制

### 6.1 日级风控

| 参数 | 值 | 含义 |
|------|---|------|
| `max_daily_trades` | 50 | 每天最多50笔，超过停止交易 |
| `max_daily_loss_pct` | 2.0% | 日亏损达2%停止交易（$200账户=亏$4停） |
| `max_daily_loss_usdt` | $20 | 绝对金额限制 |

### 6.2 连续止损熔断

连续止损次数递增冷却时间：

| 连续止损次数 | 冷却时间 | 目的 |
|-------------|---------|------|
| 第1次 | 10分钟 (`post_stoploss_cooldown_seconds=600`) | 短暂冷静 |
| 连续2次 | 20分钟 | 避免追亏 |
| 连续3次 | 2小时 | 市场可能不适合策略 |
| 连续4次+ | 4小时 | 大幅冷却，等市场环境改变 |

**重置条件**: 盈利出场（追踪止损/硬止盈/保本）立即重置计数器。每日重置。

### 6.3 交易冷却

- 每次交易后固定冷却 120秒（`cooldown_seconds`）
- 防止短时间内频繁交易

### 6.4 出场失败熔断

如果平仓订单被交易所拒绝：
- 第1-2次: 恢复持仓状态，60秒后重试
- 第3次: 强制清除持仓状态（避免死循环）

### 6.5 数据超时保护

如果持仓中超过30秒没有收到BookTicker数据 → 紧急使用K线收盘价平仓

## 七、配置参数完整说明

### 7.1 交易参数

```toml
[strategy]
symbol = "BTCUSDT"              # 交易品种
quantity_per_trade = 0.002      # 每笔BTC数量(≈$128)
take_profit_pct = 3.0           # 硬止盈上限3%
stop_loss_pct = 1.5             # 固定止损(ATR关闭时使用)
max_hold_seconds = 43200        # 最大持仓12小时
cooldown_seconds = 120          # 交易间冷却2分钟
max_daily_trades = 50           # 日最大交易笔数
max_daily_loss_pct = 2.0        # 日最大亏损%
round_trip_fee_pct = 0.1        # 往返手续费(BUY免费+SELL 0.1%)
allow_short = false             # 禁止做空(现货模式下必须为false，现货不支持裸卖空)
strategy_type = "Breakout"      # 策略类型标识
```

### 7.2 入场过滤参数

```toml
rsi_oversold = 40.0             # RSI超卖线(低于此触发"曾超卖"标记)
rsi_overbought = 100.0          # RSI超买线(100=禁用RSI退出)
volume_ratio_threshold = 1.2    # 量比最低门槛(突破路径)
min_trend_strength_pct = 0.03   # EMA趋势强度最低%(EMA7与EMA21的分离度)
max_ema50_distance_pct = 1.0    # 价格距EMA50最大%,防趋势末端追涨
mean_revert_min_slope = -0.10   # 均值回归最低斜率%,防暴跌接飞刀
breakout_min_slope = 0.05       # 突破路径最低斜率%,要求更强趋势确认
entry_score_threshold = 55      # 多因子评分入场阈值(满分100)
```

### 7.3 出场保护参数

```toml
breakeven_trigger_pct = 0.8     # 浮盈达0.8%时激活保本止损
trailing_trigger_pct = 1.0      # 浮盈达1.0%时激活追踪止损(固定%模式)
trailing_distance_pct = 0.8     # 追踪回撤距离0.8%(固定%模式)
stale_exit_seconds = 999999     # 僵尸早退时间(999999=禁用)
stale_pnl_threshold_pct = 0.3   # 僵尸判定门槛0.3%
post_stoploss_cooldown_seconds = 600  # 止损后延长冷却10分钟
```

### 7.4 ATR动态止损参数

```toml
use_atr_stops = true            # 启用ATR动态止损
atr_stop_multiplier = 8.5      # 止损距离 = 8.5 × ATR
atr_trailing_multiplier = 3.0  # 追踪触发 = 浮盈达 3.0 × ATR
atr_trailing_distance = 2.0    # 追踪距离 = 2.0 × ATR
```

**参数含义**:
- `8.5×ATR` 止损: BTC 5分钟ATR约$40-80，止损约$340-$680（0.5%-1.1%）。8.5倍给足呼吸空间，避免正常波动止出。
- `3.0×ATR` 追踪触发: 浮盈约$120-$240后开始追踪。较早追踪可以在行情反转前锁利。
- `2.0×ATR` 追踪距离: 追踪紧度适中。太紧会被波动震出，太松利润回吐多。

### 7.5 ADX趋势过滤参数

```toml
adx_min_threshold = 20.0       # ADX<20=震荡市，不入场
adx_strong_trend = 30.0        # ADX>30=强趋势，评分加分(注:当前评分无此加分)
```

### 7.6 波动率政权过滤

```toml
atr_percentile_low = 0.0       # ATR百分位下限(0=不过滤低波动)
atr_percentile_high = 100.0    # ATR百分位上限(100=不过滤高波动)
```
目前两个值设为0和100，等于禁用。未来可设为如 `20-80` 过滤极端波动。

### 7.7 风险管理参数

```toml
[risk]
max_position_usdt = 300.0      # 最大持仓金额(USDT)
max_single_order_usdt = 150.0  # 单笔最大金额(覆盖0.002×$70k=$140)
max_daily_loss_usdt = 20.0     # 日亏损绝对金额上限
min_order_interval_secs = 10   # 最小下单间隔(秒)
```

## 八、状态持久化

### 8.1 持久化内容
策略状态保存到 `data/strategy_state_btcusdt.json`，包含：
- 持仓方向、入场价、入场时间

### 8.2 原子写入
使用 `write(tmp) → rename(final)` 模式，防止并发写入或崩溃导致文件损坏。

### 8.3 启动恢复
程序重启时自动加载上次状态，带合法性校验（有持仓但price=0会被丢弃）。

## 九、盘口数据辅助决策

### 9.1 买盘支撑判定
```
bid_support = best_bid_qty > best_ask_qty × 1.5
```
含义：买一挂单量是卖一挂单量的1.5倍以上 → 说明有人在积极"接盘"。

### 9.2 点差异常保护
```
spread_pct = (ask - bid) / bid × 100%
如果 spread > 0.5% → 跳过本次信号
```
BTC正常点差<0.01%，异常点差说明流动性枯竭或极端行情。

## 十、策略设计哲学

### 10.1 为什么纯做多？
- **现货限制**: 系统连接的是Binance现货API，现货本质上只能"买入持有→卖出"，不支持裸卖空
- 代码中虽保留了做空逻辑框架（`allow_short`配置），但在现货模式下**永远不应启用**
- BTC长期趋势向上，做多有"趋势红利"
- 纯做多策略在熊市中通过不交易（各项过滤条件不满足）来保本

### 10.2 为什么三种入场路径？
- **RSI反弹**: 最常见的入场机会，利用短期超卖反弹
- **突破入场**: 捕捉趋势加速阶段的强势行情
- **均值回归**: 抓取急跌后的V形反转，不依赖趋势

三种路径互补，覆盖不同市场形态。

### 10.3 预热机制
- 1分钟K线需要21根（21分钟） → EMA21就绪
- 5分钟K线需要50根（250分钟≈4.2小时） → EMA50就绪
- 启动后约4小时才会开始交易，确保指标稳定

### 10.4 日重置逻辑
UTC每日0点（北京时间8:00）自动重置：
- 日交易笔数、日盈亏统计
- 连续止损计数和冷却时间
